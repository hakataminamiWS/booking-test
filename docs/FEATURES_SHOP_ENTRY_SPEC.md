# 店舗予約トップ画面仕様書

## 1. 目的

このドキュメントは、ユーザーが特定の店舗にアクセスした際に、ゲスト予約か会員予約かを選択するためのランディングページ（店舗予約トップ画面）の仕様を定義します。

## 2. 対象ユーザー

- 全てのユーザー（未ログイン、ログイン済み問わず）

---

## 3. 機能・画面仕様詳細

### 店舗予約トップ画面

#### 機能概要

店舗の予約を開始するための入り口となる画面です。
ユーザーはここから、会員としてログインして予約するか、会員登録せずにゲストとして予約するかを選択します。

#### 画面仕様詳細 (/shops/{shop})

##### 表示項目一覧

店舗ヘッダー：

- 店舗：{店舗名} の共通ヘッダーを表示します。

アクションセクション：

以下の2つの大きなボタン（またはリンク）を配置します。

1. ログインして予約する
   - 遷移先: /shops/{shop}/booker/bookings/create
   - 説明: 既に会員の方、または会員登録をしてから予約する場合はこちら。

2. ゲストとして予約する
   - 遷移先: /shops/{shop}/guest/bookings/create
   - 説明: 会員登録せずに予約する場合はこちら。

##### 補足: ログイン済みユーザーの挙動

ログイン済みのユーザーがこの画面にアクセスした場合の挙動は以下の通りとします。

- 店舗会員（ShopBooker）として登録済みの場合:
  - 店舗マイページ (/shops/{shop}/booker) へリダイレクトします。

- アカウントはあるが、この店舗の会員ではない場合:
  - そのままこの画面を表示します（「ログインして予約する」を選ぶと、プロフィール登録フローへ進むため）。

#### バックエンド仕様

##### データ受け渡し (ページ表示)

- ルート: GET /shops/{shop:slug}
- コントローラ: App\Http\Controllers\ShopEntryController@show
- 処理内容:
  - 公開ルートとして定義します（認証不要）。
  - ログイン済みかつ店舗会員登録済みの場合はリダイレクト処理を行います。
  - 対象の Shop オブジェクトを取得し、ビューへ渡します。
